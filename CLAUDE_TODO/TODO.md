# LLM summarize模块

1. 输入一段 prompt 或 output
2. prompt 可以被视为一个 `任务`
3. output 可以被视为一个 `结果`
4. 用 LLM 将 一个任务/结果对 转化为格式化文本

# Prompt 工程

1. 撰写提示词：
让大模型根据原始输入填空，
比如：
“你是一名工程任务规划师，根据所给任务，生成格式化文本，格式如下所示：
```
在这个环节，你知道的信息是：
1. 
2. 
3. 

在这个环节，你需要完成的任务有：
1. 
2. 
3. 
```
这些拆分的信息或任务数量不定，需要满足原子性。
”

“你是一名工程任务规划师，根据所给结果，生成格式化文本，格式如下所示：
```
在这个环节，你完成的任务有：
1. 
2. 
3. 
```
这些拆分的任务数量不定，需要满足原子性。
”

# Harness 工程

通过字符串匹配，判断是否符合提示词中的格式，如果不符合，那么重试（上限设为超参数，默认为3）

通过字符串操作，将去除提示词模版，将有效信息，转化为json格式文件
例如：
```json
{
    "prompt": [
        "请实现cli模块"
    ],
    "output": [
        "我实现了cli模块"
    ]
}
```
