# Workflow

第一步：大模型“降维提取器” (The LLM Brain)在这个阶段，LLM 被剥夺了判断对错的权力，它只做一个没有感情的“文本解构机”。输入：智能体的非结构化长日志（包含打招呼、废话、代码、系统提示）。Prompt 设定：你是一个客观的语义编译器。请阅读以下文本：忽略所有的感谢、寒暄和情绪表达。将文本中包含的实质性操作、API调用或业务结论，提取为独立的“原子声明 (Atomic Claims)”。严格输出为 JSON 数组：[{"claim_id": 1, "action": "动作A"}, {"claim_id": 2, "action": "动作B"}]结果：将几百字的冗长输出，变成了极其干净的、没有废话的 JSON 数组。第二步：算法“无情法官” (The Algorithmic Calculator)现在由你的 Python 脚本和向量算法接管。输入：上一步提取出的干净的 Claims 数组，以及原始的 Prompt 约束条件。算法执行：针对每一个 Claim，计算它与任务约束的契合度。对于 FM-2.2 (幻觉/漂移)：计算该 Claim 向量与任务上下文向量的支持度 (Support Score)。如果得分低于阈值（如 0.4），说明这是一个没有依据的“外星概念”。对于 FM-1.1 (规范违背)：将该 Claim 向量送入我们讨论过的**“对比锚点探测器”**，计算合规锚点与违规锚点的偏航梯度 (Delta)。如果 $\Delta < 0$，确诊越界。
