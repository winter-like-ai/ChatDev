# 中国首都查询系统用户手册

## 概述

中国首都查询系统是一个基于Python开发的桌面应用程序，专门用于查询和展示中国首都北京的相关信息。本软件采用图形用户界面(GUI)，提供直观、友好的用户体验。

## 主要功能

### 1. 核心查询功能
- **基本答案查询**：直接回答"中国的首都是哪里？"这个问题
- **多语言支持**：支持中文和英文两种语言显示答案
- **实时切换**：用户可随时切换显示语言

### 2. 详细信息展示
- 北京的人口统计数据
- 北京的面积信息
- 北京成为首都的时间
- 北京的著名地标建筑

### 3. 趣味知识
- 提供关于北京的5个有趣事实
- 涵盖历史、文化、建筑等多个方面

### 4. 用户界面特性
- 现代化GUI设计
- 响应式布局
- 美观的配色方案
- 窗口居中显示

## 系统要求

### 硬件要求
- 处理器：1GHz或更高
- 内存：512MB RAM（推荐1GB）
- 硬盘空间：10MB可用空间

### 软件要求
- 操作系统：Windows 7/8/10/11, macOS, Linux
- Python版本：Python 3.6或更高版本

## 安装指南

### 步骤1：安装Python
如果您还没有安装Python，请按照以下步骤操作：

1. 访问 [Python官方网站](https://www.python.org/downloads/)
2. 下载适合您操作系统的Python安装包
3. 运行安装程序，**务必勾选"Add Python to PATH"选项**
4. 完成安装

### 步骤2：验证Python安装
打开命令行工具（Windows：CMD或PowerShell，macOS/Linux：终端），输入：
```bash
python --version
```
或
```bash
python3 --version
```
如果显示Python版本号（如Python 3.9.0），说明安装成功。

### 步骤3：准备软件文件
1. 创建一个新文件夹，例如"CapitalApp"
2. 将以下文件保存到该文件夹中：
   - `main.py`
   - `capital_finder.py`
   - `gui.py`
   - `requirements.txt`

### 步骤4：安装依赖
在命令行中，导航到软件文件夹：
```bash
cd path/to/CapitalApp
```
然后安装所需依赖：
```bash
pip install -r requirements.txt
```

## 使用指南

### 启动应用程序
1. 打开命令行工具
2. 导航到软件文件夹：
   ```bash
   cd path/to/CapitalApp
   ```
3. 运行主程序：
   ```bash
   python main.py
   ```
   或
   ```bash
   python3 main.py
   ```

### 界面说明

#### 主界面布局
应用程序启动后，您将看到以下界面：

1. **标题区域**
   - 显示"中国首都查询系统"
   - 英文副标题"Capital of China Information System"

2. **问题区域**
   - 显示问题："中国的首都是哪里？"

3. **答案区域**
   - 显示当前语言的答案
   - 中文默认显示："中国的首都是北京。"

4. **语言选择区域**
   - 下拉菜单选择显示语言
   - 支持"中文"和"English"

5. **功能按钮区域**
   - **详细信息**按钮：查看北京的详细信息
   - **有趣事实**按钮：查看关于北京的有趣事实
   - **退出**按钮：关闭应用程序

### 功能操作

#### 切换语言
1. 点击语言选择下拉菜单
2. 选择"中文"或"English"
3. 答案区域将立即更新为所选语言

#### 查看详细信息
1. 点击"详细信息"按钮
2. 将弹出对话框显示：
   - 国家名称（中英文）
   - 首都名称（中英文）
   - 人口信息
   - 面积信息
   - 成为首都时间
   - 著名地标列表

#### 查看有趣事实
1. 点击"有趣事实"按钮
2. 将弹出对话框显示5个关于北京的有趣事实
3. 内容包括历史、文化、建筑等方面的知识

#### 退出程序
- 点击"退出"按钮
- 或直接关闭窗口

## 故障排除

### 常见问题

#### 问题1：无法启动程序
**症状**：运行`python main.py`时出现错误
**解决方案**：
1. 确认Python已正确安装
2. 确认已安装tkinter：
   ```bash
   python -m tkinter
   ```
3. 确认所有文件都在同一文件夹中

#### 问题2：界面显示异常
**症状**：字体显示不正确或布局混乱
**解决方案**：
1. 确保系统安装了中文字体
2. Windows用户可安装"Microsoft YaHei"字体
3. 尝试调整窗口大小

#### 问题3：依赖安装失败
**症状**：`pip install`命令失败
**解决方案**：
1. 更新pip：
   ```bash
   pip install --upgrade pip
   ```
2. 使用国内镜像源：
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

### 错误代码说明

| 错误代码 | 描述 | 解决方案 |
|---------|------|----------|
| ModuleNotFoundError | 缺少模块 | 运行`pip install tkinter` |
| ImportError | 导入错误 | 检查文件路径和名称 |
| TclError | Tkinter错误 | 检查Python和tkinter版本 |

- `CapitalApp`类：主GUI应用程序
- 使用tkinter构建界面
- 事件处理：语言切换、按钮点击
