# 首都信息文档生成器 - 用户手册

## 📋 产品概述

首都信息文档生成器是一款专为回答"中国的首都是哪里？"这一问题而设计的智能软件。它不仅提供准确的答案，还能生成包含详细首都信息的专业文档，并支持扩展查询其他国家首都信息。

### 主要功能特点

1. **核心问答功能** - 准确回答中国首都问题
2. **文档自动生成** - 生成格式规范的文本文档
3. **详细信息展示** - 提供北京的人口、面积、历史等详细信息
4. **多国首都对比** - 内置多个国家首都数据对比
5. **可选GUI界面** - 提供图形化查询界面（可选功能）
6. **多语言支持** - 支持中英文显示
7. **时间戳记录** - 自动记录文档生成时间

## 🚀 快速开始

### 环境要求

- **Python版本**: Python 3.6 或更高版本
- **操作系统**: Windows, macOS, Linux
- **内存**: 至少 512MB RAM
- **磁盘空间**: 至少 10MB 可用空间

### 安装步骤

#### 方法一：直接运行（推荐）

1. 确保已安装Python 3.6+
   ```bash
   python --version
   ```

2. 下载项目文件到本地目录：
   - `main.py` - 主程序文件
   - `capital_facts.py` - 数据文件
   - `gui_app.py` - 可选GUI界面文件

3. 打开终端或命令提示符，进入文件所在目录

4. 运行主程序：
   ```bash
   python main.py
   ```

#### 方法二：创建虚拟环境（高级用户）

1. 创建虚拟环境：
   ```bash
   python -m venv capital_env
   ```

2. 激活虚拟环境：
   - **Windows**:
     ```bash
     capital_env\Scripts\activate
     ```
   - **macOS/Linux**:
     ```bash
     source capital_env/bin/activate
     ```

3. 运行程序：
   ```bash
   python main.py
   ```

## 📖 使用指南

### 基础使用（命令行模式）

#### 1. 生成首都信息文档

运行以下命令生成包含中国首都信息的文档：
```bash
python main.py
```

**输出结果：**
- 在控制台显示完整的首都信息
- 自动生成一个文本文件，命名格式：`capital_info_YYYYMMDD_HHMMSS.txt`
- 文件包含：
  - 生成时间戳
  - 问题及答案
  - 中国首都详细信息
  - 其他主要国家首都对比表

#### 2. 查看生成的文件

程序运行后，会在当前目录生成类似以下文件：
```

```

用任何文本编辑器打开即可查看完整内容。

### 高级使用（GUI界面）

#### 1. 启动图形界面

运行GUI应用程序：
```bash
python gui_app.py
```

#### 2. GUI界面功能说明

界面分为以下几个主要区域：

**A. 用户问题区域**
- 显示问题："中国的首都是哪里？"
- 点击"获取答案"按钮显示答案

**B. 中国首都详细信息区域**
- 显示国家、首都（中英文）、人口、面积、建都时间
- 所有信息以清晰格式展示

**C. 有趣事实区域**
- 显示关于北京的4个有趣事实
- 支持滚动查看

**D. 其他主要国家首都区域**
- 表格显示美国、日本、法国等国家首都信息
- 包含国家、首都、人口、面积列
- 支持滚动查看

**E. 搜索功能区域**
- 输入国家名称搜索其首都信息
- 支持模糊搜索（不区分大小写）

#### 3. GUI操作步骤

1. **查看答案**：
   - 点击"获取答案"按钮
   - 弹出对话框显示："中国的首都是北京 (Beijing)"

2. **搜索其他国家**：
   - 在搜索框输入国家名称（如：Japan, France, United States）
   - 点击"搜索"按钮
   - 显示该国家首都的详细信息

3. **浏览信息**：
   - 使用滚动条查看所有内容
   - 表格支持垂直滚动

## 🛠️ 故障排除

### 常见问题

#### 1. Python未安装
**症状**：运行`python main.py`时提示"python不是内部或外部命令"
**解决方案**：
- 访问[python.org](https://www.python.org)下载并安装Python
- 安装时勾选"Add Python to PATH"

#### 2. 中文显示乱码
**症状**：控制台或生成文件中中文显示为乱码
**解决方案**：
- 确保使用支持UTF-8的终端（如Windows Terminal）
- 文本编辑器使用UTF-8编码打开文件

#### 3. GUI界面无法启动
**症状**：运行`python gui_app.py`时报错
**解决方案**：
- 确保已安装tkinter（Python标准库的一部分）
- 对于某些Linux系统，可能需要安装tkinter：
  ```bash
  sudo apt-get install python3-tk
  ```

#### 4. 文件权限问题
**症状**：无法生成文本文件
**解决方案**：
- 确保对当前目录有写入权限
- 尝试以管理员身份运行（Windows）或使用sudo（Linux/macOS）

### 错误代码说明

程序没有特定的错误代码，但可能遇到以下情况：

1. **ImportError**：缺少必要文件
   - 确保`capital_facts.py`与`main.py`在同一目录

2. **FileNotFoundError**：文件路径问题
   - 确保在正确的目录运行程序

3. **UnicodeEncodeError**：编码问题
   - 程序已内置UTF-8编码处理，如仍出现问题请检查系统区域设置
