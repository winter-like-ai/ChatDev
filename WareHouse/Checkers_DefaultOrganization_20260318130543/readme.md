# Checkers (Draughts) Game
A fully functional Checkers game with graphical user interface implemented in Python using Pygame.
## Features
- 8x8 checkers board with standard starting positions
- Two-player alternating turns (Red vs White)
- Standard checkers movement rules
- Mandatory capture enforcement
- King piece promotion (crowned pieces)
- Multiple jumps in a single turn
- Visual highlighting of selected pieces and valid moves
- Game state tracking and win detection
- Move notation display
