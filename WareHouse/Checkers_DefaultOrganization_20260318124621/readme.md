# Checkers (Draughts) Game
A fully functional Checkers game implemented in Python with Pygame GUI.
## Features
- 8x8 standard Checkers board
- Two-player alternating turns (Red vs Black)
- Standard capture rules (mandatory captures)
- King promotion rules
- Chain captures (multiple jumps in one turn)
- Graphical user interface with Pygame
- Visual highlights for selected pieces and valid moves
- Game state tracking (piece counts, kings, current player)
- Game over detection and winner announcement
- Reset and quit functionality
